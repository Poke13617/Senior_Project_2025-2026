# Senior_Project_2025-2026

What is this project?

- This project is a text-based game where the goal will be to outlast a set timer. The NPCs will be 4 different allies that support you in the same sense as an asymmetrical horror game. The character chosen will have different kits as follows:

  1.Offense: Carries 2 in-your-face offense abilities that work very similar to each other. 

  2.Support: carries a heal that stays in place and a roll that carries a little mobility and a lower cooldown. Carries no stun time.

  3.Defense: carries a charge that damages itself and stuns the enemy for 4 turns, the highest stun time in the game at the tradeoff of no mobility
